About Nocturne

Nocturne is a web-based developer toolkit. It bundles a code editor, cloud virtual machines, an AI assistant, and everyday browser utilities into a single platform.

What we offer

  • Code editor — write and run code directly in the browser with syntax highlighting and language support.
  • Cloud VMs — spin up on-demand virtual machines for development, testing, and learning.
  • AI assistant — ask questions, generate code, and get help with projects.
  • Developer tools — Base64, JSON formatter, hash generator, QR codes, UUIDs, and timestamp converter.
  • Link checker — test URL accessibility across multiple web filters.
  • Chat & voice — collaborate with other users in real time.

Built by

Nocturne is maintained by midnightsweat and a small team of contributors. The platform runs on Node.js and vanilla JavaScript with no heavy framework dependencies.
